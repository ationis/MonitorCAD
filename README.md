# MonitorCAD — Мониторинг изменений технической документации в КОМПАС-3D

**MonitorCAD** — это десктопное приложение на Python, разработанное конструктором (без профильного IT-образования) с использованием инструментов ИИ. 

Программа автоматически отслеживает изменения в 3D-моделях (`.m3d`) и чертежах (`.cdw`) КОМПАС-3D, проверяет актуальность чертежей и DXF-разверток, а также формирует список изменений для отправки коллегам.

## 🎯 Решаемая проблема
В конструкторских бюро часто возникает ситуация: деталь в 3D изменили, но чертёж не перестроили, или развертка для лазерного станка устарела. Снабжение закупает металл по старым размерам, производство запускает брак. 

MonitorCAD решает это, автоматически сравнивая **интегральные характеристики (МЦХ)** деталей и **массу в штампе чертежа**, исключая ложные срабатывания при простом пересохранении файлов.

## ✨ Ключевые возможности
* **Умное отслеживание:** Сравнение не по дате изменения файла, а по физическим параметрам (Масса, Объем, Центр масс, Моменты инерции).
* **Контроль чертежей:** Сверка массы из 3D-модели с массой, указанной в штампе чертежа (`.cdw`). Если массы совпадают — чертеж актуален.
* **Контроль листовых деталей:** Проверка наличия и актуальности DXF-разверток для листового металла.
* **Журнал изменений:** Ведение истории изменений, которая переживает перезапуск программы.
* **Быстрая рассылка:** Формирование HTML-таблицы изменений и копирование её в буфер обмена для отправки по почте.
* **Работа в трее:** Программа сворачивается в системный трей и не мешает работе.
